# SOM Customer Service Booking

An Android application for booking customer services.

## Stage 1: Architecture and Models

This stage focuses on setting up the foundation of the project:
- Data Models (`Service`, `AvailabilitySlot`, `Booking`)
- API Interface (`ApiService`)
- Repository Layer (`ServiceRepository`)
- Project Package Structure

## Project Structure

- `model/`: Data classes representing the domain objects.
- `data/`: Data source abstractions and implementations.
- `ui/`: Compose screens and components (to be implemented).
- `navigation/`: Navigation logic (to be implemented).
- `viewmodel/`: Business logic for the UI (to be implemented).
